All 16 project-page video recordings are converted to GIF for playback in GitHub Markdown; the original video links remain available.

GIFs preserve the source framing and sequence, resize to width 352 with the same aspect ratio, sample at 5 fps and use a 128-color palette. They loop without audio. They are viewing previews rather than timing or image-quality measurements. No frame content is generated or retouched. Source and derived-file hashes are recorded separately.

The gallery includes every task ID from 01 through 16 exactly once, with a preview and original-video link. Selected executions do not estimate success frequency. Phone-box assembly is supplementary and is excluded from the paper's 15-task macro average. The repository's single 28D training interface does not imply that all demonstrated tasks are bundled.

## Method and Prediction Assets

| File / pattern | Source | Meaning |
|---|---|---|
| `overview.webp` | `assets/images/overview.webp` | Full paper method, including post-training outside this release |
| `response_allocation.webp` | `assets/images/allocation.webp` | Fixed-policy supervision allocation and response/error comparison |
| `credit_dynamics.webp` | `assets/images/credit-dynamics.webp` | Spatial prior evolution and spatiotemporal credit diagnostics |
| `phone_{recorded,predicted}_{4,8,16}.webp` | `assets/images/predictions/phone-*.webp` | Matched physical training-window continuations |
| `robodojo_{recorded,predicted}_{4,8,16}.webp` | `assets/images/predictions/task_00-*.webp` | Matched RoboDojo “Arrange numbers” training-window continuations |

Prediction images are training-window diagnostics, separate from task-success evaluation. Signal-analysis figures do not establish a causal effect on robot performance. These media are attributed research illustrations, not redistributed datasets, model weights or results generated by the public recipe.

[provenance/media.json](../../provenance/media.json) records every local filename, source URL, source/derived hash, purpose and transformation. All captions and filenames in the release use English and the public RAP-WAM naming conventions.
